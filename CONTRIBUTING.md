# Contributing to Heroshot

Contributions are warmly welcomed! Whether it's a bug report, feature idea, or a pull request — every bit helps make Heroshot better for everyone.

## The most helpful thing you can do

If you hit a limitation, have a use case that isn't covered, or just have an idea — **please open an issue or start a discussion**. Even if you're not sure it's worth mentioning, it probably is.

I'd much rather hear about what's missing and fill the gaps than have people work around problems in private forks. If something doesn't work for you, chances are others are hitting the same thing.

## Ways to contribute

- **Report a bug** — [open an issue](https://github.com/omachala/heroshot/issues/new) with what you expected vs. what happened
- **Suggest a feature** — describe your use case, the problem matters more than the solution
- **Submit a PR** — fork the repo, make your changes, and open a pull request
- **Share your experience** — join the [discussions](https://github.com/omachala/heroshot/discussions) and let us know how you're using Heroshot

## Getting started

```bash
git clone https://github.com/<your-username>/heroshot.git
cd heroshot
pnpm install
pnpm build
```

Run the CLI in development mode:

```bash
pnpm dev
```

Run tests:

```bash
pnpm test:run
```

## Pull requests

- Fork the repo and create your branch from `main`
- Keep changes focused — one feature or fix per PR
- Make sure `pnpm check` passes before submitting
- Describe what your PR does and why

## No contribution is too small

Typo fixes, documentation improvements, better error messages — all welcome. Don't hesitate.
