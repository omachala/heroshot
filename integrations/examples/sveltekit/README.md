# SvelteKit + Heroshot Example

Minimal SvelteKit setup with heroshot integration.

## Quick Start

```bash
pnpm install
pnpm dev
```

Open http://localhost:5173

## What's Included

- `heroshot/plugins/vite` - Auto-loads manifest
- `heroshot/sveltekit` - `<Heroshot>` Svelte component
- Theme-aware screenshots (toggle dark mode to see it switch)

## Capture Screenshots

```bash
npx heroshot
```
