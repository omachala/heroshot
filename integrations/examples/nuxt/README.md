# Nuxt + Heroshot Example

Minimal Nuxt setup with heroshot integration.

## Quick Start

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000

## What's Included

- `heroshot/plugins/vite` - Auto-loads manifest via Vite plugin
- `heroshot/nuxt` - `<Heroshot>` Vue component
- Theme-aware screenshots (toggle dark mode to see it switch)

## Capture Screenshots

```bash
npx heroshot
```
