# VitePress + Heroshot Example

Minimal VitePress setup with heroshot integration.

## Quick Start

```bash
pnpm install
pnpm dev
```

Open http://localhost:5173

## What's Included

- `heroshot/plugins/vite` - Auto-loads manifest
- `heroshot/vitepress` - `<Heroshot>` component
- Theme-aware screenshots (toggle dark mode to see it switch)

## Capture Screenshots

```bash
npx heroshot
```
