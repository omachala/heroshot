# MkDocs + Heroshot Example

Minimal MkDocs Material setup with heroshot integration.

## Quick Start

```bash
pip install -r requirements.txt
mkdocs serve
```

Open http://localhost:8000

## What's Included

- `heroshot` PyPI package with MkDocs macro
- `{{ heroshot("name", "alt") }}` macro for theme-aware screenshots
- Material theme with dark mode toggle

## Capture Screenshots

```bash
npx heroshot
```
