# Docusaurus + Heroshot Example

Minimal Docusaurus setup with heroshot integration.

## Quick Start

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000

## What's Included

- `heroshot/plugins/docusaurus` - Auto-loads manifest via webpack
- `heroshot/docusaurus` - `<Heroshot>` React component
- Theme-aware screenshots (toggle dark mode to see it switch)

## Capture Screenshots

```bash
npx heroshot
```
