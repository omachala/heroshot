# What is Heroshot?

Heroshot is a screenshot automation CLI tool that helps you capture perfect screenshots of web pages with interactive element selection.

## Features

- **Interactive Element Picker** - Click to select any element on the page
- **Visual Toolbar** - Adjust padding, toggle modes, and preview selections
- **Playwright Powered** - Reliable, headless browser automation
- **CLI First** - Simple commands that fit into your workflow

## Use Cases

- **Documentation** - Capture UI screenshots for docs
- **Marketing** - Create hero images for landing pages
- **Testing** - Visual regression testing snapshots
- **Design** - Export components for design systems
