Enter your app URL to get started

Press Enter or use the browser address bar

Toolbar Shortcuts
Click Pick element
Drag Symmetric resize (both sides)
Shift+Drag Single side / corner only
Esc Cancel / revert changes
Click pad Toggle mask fill
CLI Commands
heroshot setup Open browser to configure screenshots
heroshot sync Capture all configured screenshots
heroshot sync --dry-run Preview without saving files
heroshot session-key Print session key for CI
Quick Actions
Pick - Click crosshair, then click element
Resize - Drag handles to add padding
Mask - Click padding to fill with bg color
Done - Save and run heroshot sync
Config Options
outputDirectory Where to save screenshots
browser.viewport Width and height in pixels
browser.colorScheme light | dark | both
browser.deviceScaleFactor 1 (standard) or 2 (retina)
Resize Modes
Edge - Default: both sides. Shift: single
Corner - Default: all 4. Shift: only 2
