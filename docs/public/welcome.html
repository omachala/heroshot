Toolbar Guide

The Heroshot toolbar helps you select elements and configure screenshot padding. Here's how to use it:

Picking Elements

Click the crosshair button in the toolbar, then click on any element on the page to select it. The element will be highlighted and you can adjust the padding around it.

Adjusting Padding

Use the resize handles around the selected element to adjust padding. Heroshot uses symmetric resizing by default for intuitive control:

Edge Handles (sides)

Default: Resizes both opposite sides together (left+right or top+bottom)

Hold Shift: Resize only that single side

Corner Handles

Default: Resizes all 4 sides equally (proportional)

Hold Shift: Resize only the 2 sides of that corner

Tip

The cursor tooltip shows the current padding values and total capture size as you drag.

Padding Fill (Mask)

Click on any padding area to toggle between transparent and masked mode. When masked, the padding area will be filled with the detected background color during capture.

Keyboard Shortcuts

Esc - Cancel selection or revert changes

Next Steps

Once you've configured your screenshots, click Done in the toolbar to save your configuration. Then run heroshot sync to capture all screenshots.
